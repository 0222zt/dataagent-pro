# 模拟数据：销售明细（2025 全年）

用于演示 / 测试 DataAgent Pro 的一份"看起来像真的"销售流水。

| 文件 | 用途 |
| --- | --- |
| `示例数据_销售明细.csv` | UTF-8 BOM 编码，Excel 双击打开不乱码，可直接拖进 DataAgent |
| `示例数据_销售明细.xlsx` | 带冻结表头、自动筛选、列宽和金额 / 百分比格式 |

- **360 行 × 19 列**，日期范围 `2025-01-02` → `2025-12-31`
- 销售额合计约 **60.2 万元**
- 故意留了 **11 个缺失的客户评分**（约 2%），用来演示缺失值处理
- 固定随机种子生成，可重复复现

重新生成：

```bat
python scripts\generate_sample_data.py
```

## 列说明

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| 订单号 | 文本 | `SO2025xxxxx`，唯一 |
| 日期 | 日期 | 下单日期，ISO 格式 |
| 月份 | 文本 | `YYYY-MM`，方便直接分组 |
| 区域 | 类别 | 华东 / 华北 / 华南 / 西南 / 华中 |
| 城市 | 类别 | 每个区域 5 个城市 |
| 产品类别 | 类别 | 家用电器 / 数码配件 / 办公用品 / 家居生活 / 户外运动 |
| 产品名称 | 类别 | 每个类别 5 个 SKU |
| 销售渠道 | 类别 | 线上商城 / 线下门店 / 经销商 / 直播带货 |
| 销售员 | 类别 | 8 位销售 |
| 数量 | 整数 | 订单件数 |
| 单价 | 数值 | 含税单价（元） |
| 折扣 | 小数 | `0.05` 表示 5% 折扣 |
| 销售额 | 数值 | 数量 × 单价 × (1 - 折扣) |
| 成本 | 数值 | 按品类成本率估算 |
| 毛利 | 数值 | 销售额 - 成本 |
| 毛利率 | 小数 | 毛利 / 销售额 |
| 客户评分 | 数值 | 3.0 - 5.0，约 2% 缺失 |
| 是否新客 | 文本 | 是 / 否 |
| 是否促销 | 文本 | 是 / 否（有折扣即视为促销） |

## 可以直接点这些推荐问题

1. 按月统计销售额，画折线图并标出最高点
2. 各区域销售额对比，柱状图从高到低排序
3. 各产品类别的销售额占比，饼图合并占比小于 5% 的类别
4. 销售额与毛利的关系，画散点图并添加趋势线
5. 各销售渠道的平均客单价对比
6. 销售员销售额排行榜前 5 名
7. 月份 × 区域 的销售额热力图
8. 客户评分的分布，并检查缺失情况
9. 新客与老客的客单价、毛利率对比
10. 只看华东区域，按产品类别画堆叠柱状图

## 数据是假的，但结构是真的

- 区域 / 渠道 / 品类分布带权重，不是均匀随机；
- 单价、成本率按品类有差异；
- 数量越大越容易触发折扣，折扣会拉低毛利率；
- 9-12 月是旺季，订单量更高；
- 客户评分集中在 4.4 左右，符合真实评价分布。

因此用它演示「趋势、对比、占比、相关性、排行榜、缺失值体检」都有意义。
